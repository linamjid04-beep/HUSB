# Guide admin brouillon

## Acces
L'administration est disponible en local sur `/admin/` apres creation d'un superutilisateur.

## Offres d'emploi
- Creer une offre dans `Offres d'emploi`.
- Renseigner titre, slug, localisation, type de contrat, resume, description et statut.
- Cocher `visible publiquement` pour afficher l'offre sur la page recrutement.
- Decochee, l'offre reste en admin mais disparait du site public.

## Demandes de contact
- Les demandes du formulaire general sont visibles dans `Demandes de contact`.
- Le champ `traitee` permet un suivi simple.

## Demandes de devis materiel
- Les demandes dediees au materiel sont visibles dans `Demandes de devis materiel`.
- Le statut peut etre: Nouveau, En cours, Traite, Archive.

## Limites du lot
Le lot n'envoie pas d'e-mails reels et ne gere pas les candidatures avec CV.
